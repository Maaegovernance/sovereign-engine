# Sovereign Engine

**Multi-Agent Alignment Engine (MAAE)** with Khalsa-principled governance.

Enforces **conjunctive quorum**: AI council + human sangat + physical sensors.

No action executes without all three layers simultaneously.

## Three Khalsa Invariants

1. **No action without sangat** — Conjunctive quorum required (AI + human + sensors)
2. **No hierarchy of persons** — No bypass lists, no root users, no exceptions
3. **No hidden authority** — Every action signed, logged, and fully reconstructible

## Core Architecture

- **Sensing (Mycelium)** — Hardware-signed sensor frames (ATECC608A)
- **Ledger** — Append-only, hash-chained, Merkle-sealed epochs
- **Council** — 7-AI deliberation under policy envelope
- **Sovereign Kernel** — Enforces the three invariants
- **Actuation** — `execute_if_authorized` only
